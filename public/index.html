REST API Specifications & Interactive Testing

Comprehensive endpoint documentation matching Task 1 and Task 2 requirements.

POST /api/patients

Add a new patient with name, phone, consultation date, next follow-up date, and clinical notes.

curl -X POST http://localhost:3000/api/patients \
  -H "Content-Type: application/json" \
  -d '{
    "name": "David Miller",
    "phone": "+1-555-0199",
    "consultation_date": "2026-11-10",
    "next_followup_date": "2026-11-16",
    "doctor_name": "Dr. Sarah Mitchell",
    "condition_or_treatment": "Post-Op Wound Care",
    "notes": "Check for redness, warmth, or drainage."
  }'
GET /api/patients

Retrieve all patients. Optional query filter: ?status=pending|completed.

curl http://localhost:3000/api/patients
GET /api/patients/due-today

Retrieve patients whose follow-up is due today (and status is pending). Optional: ?date=YYYY-MM-DD.

curl http://localhost:3000/api/patients/due-today
PATCH /api/patients/:id/status

Update a patient's follow-up status to completed or pending.

curl -X PATCH http://localhost:3000/api/patients/1/status \
  -H "Content-Type: application/json" \
  -d '{"status": "completed"}'
POST /api/ai/generate-draft/:patientId

Generate personalized WhatsApp follow-up draft using Gemini or Clinical Mock Engine.

curl -X POST http://localhost:3000/api/ai/generate-draft/1 \
  -H "Content-Type: application/json" \
  -d '{"tone": "caring"}'
PATCH /api/ai/drafts/:id/review

Staff review & approval: edits draft, marks approved, simulates mock WhatsApp dispatch, and auto-completes follow-up.

curl -X PATCH http://localhost:3000/api/ai/drafts/1/review \
  -H "Content-Type: application/json" \
  -d '{
    "status": "approved",
    "reviewer": "Nurse Alex",
    "edited_message": "Customized message..."
  }'
